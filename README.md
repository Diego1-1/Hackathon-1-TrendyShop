El proyecto está dirigido principalmente a personas interesadas en practicar actividades deportivas y recreativas que necesitan alquilar espacios deportivos por horas, tales como canchas de fútbol, vóley, básquet y losas multiusos. El público objetivo comprende principalmente jóvenes y adultos en zonas urbanas, incluyendo estudiantes, trabajadores, grupos de amigos, deportistas aficionados y personas que practican actividades físicas de manera individual o colectiva.

Misión 
Brindar una plataforma web accesible, segura y fácil de utilizar que permita a las personas encontrar, consultar y reservar espacios deportivos de actividades deportivas y recreativas de manera rápida y eficiente, centralizando diferentes opciones y tipos losas en un solo lugar.

Visión 
Ser una plataforma de referencia para la reserva de espacios para actividades deportivas y recreativas, facilitando el acceso a actividades deportivas y contribuyendo a una experiencia moderna, organizada y conveniente tanto para los usuarios como para los establecimientos deportivos.
